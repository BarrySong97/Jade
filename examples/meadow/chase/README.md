# 草丛追蝶

入口仍在原花草 demo：<http://localhost:55022/#chase-scene>。运行 `pnpm demo:meadow`；已有标签页需要刷新。独立猫画板和蝴蝶画板继续保留。

这是固定镜头的二维合成：奶白小猫半藏在前景草叶后，暖杏蝴蝶先飞过，猫伏低探头；蝴蝶落到花上后，猫专注等 1.25 / 1.8 / 1.5 秒，再起跑直接接扑跳。猫接近花头时蝴蝶绕开，猫落地恢复，移动到另一侧草里、转身伏低。六轮组合交替方向、白雏菊/黄色野花和等待时间，然后继续循环；没有重置猫的位置。

## 原画

三张均由内置 ImageGen 参考已确认的猫/蝴蝶原画生成，1774 × 887、四列两行、真实 alpha。原始文件直接保存，不程序抠图、重画或导出裁切图片。

- [cat-stalk-v1.png](cat-stalk-v1.png)：站立→伏低→抬头观察。探头保持腹部低，抬起头颈。
- [cat-dash-v1.png](cat-dash-v1.png)：伏低起跑及跑动接扑跳。补足身体重心转移，避免跑步后先站定再跳。
- [butterfly-perch-v1.png](butterfly-perch-v1.png)：收翅落花与展开起飞，细脚作为花头接触位置。

两张猫图首版靠近格边，用 ImageGen 缩小并补留白。全部生成和修正提示词、参考与源文件在 [prompt-chase-v1.json](prompt-chase-v1.json)。旧的跑步、跳跃、起跑收步、恢复、转身及振翅图集继续复用；部分新图端点由旧姿势替代，以减少切换差异。

## 如何合在一起

- [chase-assets.mjs](chase-assets.mjs)：定义图集采样区和身体/足部锚点，同组保持统一缩放。跑步接触帧按真实脚底注册，腾空帧保留抬脚姿势。运行时只改变采样姿势和位置，未将猫转成真实骨骼模型。
- [chase-layout.mjs](chase-layout.mjs)：复用首页的自然排布，调整两朵停驻花、四株藏身草与三株沿路低草，不增加株数。猫的地面线位于底边下方 0.12 个身高单位，脚尖埋在草根内；前草保持原深度，不跟猫一起下移。原图花心注册到裁切、镜像后的网格，使用与绘制一致的 9 行分段风动插值。
- [chase-motion.mjs](chase-motion.mjs)：双方共用时间线，落花后才开始 1–2 秒的专注等待；逃离时刻通过猫进入花头接近区求解，并使用当前循环的真实风动位置。猫跑动、蹬地和空中段连续前移，落地减速后恢复。方向、选择的花和时长变化是预设组合，不是实时物理或随机 AI。
- [chase-renderer.js](chase-renderer.js)：一个 WebGL 画布，按后景花草→接触阴影→猫→前景草→蝴蝶绘制。很淡的软阴影固定在地面，猫跳起时变淡，不跟着上浮；静态回退也使用同一套参数。草保留二维网格形变，动物播放原画姿势；预乘 alpha 避免黑边。蝴蝶停驻足部贴着花头随风移动，猫走到前草后自然被遮挡。
- [chase-board.js](chase-board.js)：暂停、0.5× / 0.25× 慢放、这一轮进度、从头播放。后台/屏外停止累计时间，尺寸变化保留同一轮/阶段/进度；减少动态效果时默认暂停。WebGL 失败或丢失时显示 Canvas 2D 静态组合，恢复上下文后续播。

用户最终决定猫与追逐只保留在 demo，首页采用花草与两色蝴蝶，见 [蝴蝶说明](../butterfly/README.md)。独立猫画板的关节辅助线保留在原处，未给新增图集宣称骨骼驱动。

## 验证与局限

[chase.test.mjs](../../../scripts/chase.test.mjs) 接入 `pnpm check`：真实透明图集/留白、伏低和探头轮廓差、落花后等待、猫接近事件、花头投影、跑扑速度、阶段/循环位置、响应式进度保持，以及 240–1327px 宽度的主体范围检查。只允许猫脚底埋进下边界，头身和蝴蝶不裁切。另检查真实落脚帧贴地、阴影地面高度不变且腾空变淡；前草覆盖继续采样原图 alpha。

用户指出首版像踩在草叶上后，将脚底线下移约 19–23px（335px / 1327px 画布），校正两个跑步落脚帧，并增加沿路遮挡和接触阴影。旧测试只检查“没有越出画布”，无法判断落脚是否处于草根地面，因此补入上述贴地回归。

位置信息连续不代表生成姿势的毛发、体型细节完全一致；转身、跨图集接缝和扑跳节奏仍需实际看页面。延续用户自行打开原 demo 的选择，未重新控制浏览器，不能把 PNG/纯函数/HTTP 检查当成浏览器视觉验收。
