# 草甸小猫 · 造型初稿

[cat-idle-v1.png](cat-idle-v1.png) 是按用户提供的猫照片生成的第一版透明坐姿原画。使用内置 ImageGen，保留生成结果与 alpha；[完整提示词及来源](prompt-v1.json) 可追溯。

照片作为脸部与毛色参考：奶白短毛、圆脸、淡粉耳内和照片光线下的深蓝灰眼睛。照片未完整展示的脚与尾巴按可见体型补全，因此这些部位是设计推演。画面笔触、明暗色块与光线参考既有白雏菊素材。私人原始照片不复制进仓库。

已选行为方向是自然小猫：以观察、蹲伏、甩尾为主，偶尔跑跳。当前包含静态原画、身体/尾巴两张分层初稿、同页独立 Canvas 的跑跳演示与尾巴网格实验；尚未接入首页。

运行 `pnpm demo:meadow`，在原花草比较页的素材区查看小猫卡片：<http://localhost:55022/#cat-sample>。小猫与三张花草姿态素材并排展示，点击可打开透明原图。后来补充的伏低探头、起跑接扑跳与草丛追蝶合成见 [追蝶场景](../chase/README.md)，入口仍在同一页面。

验证：检查全身轮廓、脸部相似度与画风，并解码确认有真实透明像素和接近不透明的主体。浏览器检查同页卡片加载、窄屏布局和原有草甸场景正常。

## 身体与尾巴分层初稿

- [body-no-tail-v1.png](body-no-tail-v1.png)：移除尾巴，补画原来被遮挡的后腿、脚和身体底部；头、躯干和前腿保持同一坐姿。
- [tail-v1.png](tail-v1.png)：独立弯曲尾巴；首轮生成的尾根有尖角，第二次局部编辑修整为较圆的轮廓。
- 两张文件均为 1254 × 1254 透明 PNG，保留原画坐标及生成结果的 alpha，未用程序裁切或重画像素。生成补画不等于逐像素无损分割，尾巴轮廓和毛发细节会与原图略有变化。
- 生成方式为内置 ImageGen，完整首轮与修正提示词、生成文件名见 [prompt-layers-v1.json](prompt-layers-v1.json)。
- 同页查看 <http://localhost:55022/#cat-layers>：身体、放大的尾巴局部和两张图片按同尺寸同坐标叠合的对照。尾巴缩略图使用 SVG viewBox 查看局部，文件本身仍是完整画布；叠合区域使用两个原始 PNG，不能按各自内容边界独立居中。
- 两张素材已接入下方所述网格摆动实验；用户选择自行打开 demo，浏览器画面和动态接缝仍需实际查看。

## 独立尾巴动画板

入口仍在同一页面：<http://localhost:55022/#cat-board>。猫使用自己的 WebGL Canvas、网格叠加 Canvas 与控件，不进入花草场景，也不共享其播放状态。

- [cat-board.js](cat-board.js) 负责动作选择、慢放、暂停、尾巴幅度、网格、只看尾巴、ResizeObserver、屏外与后台暂停；减少动态效果时默认静止，主动点击动作才播放。资源或 WebGL 失败时回退到两张 PNG 的静态叠合。
- [cat-renderer.js](cat-renderer.js) 静态绘制完整身体，尾巴用 19 × 9 顶点的局部矩形网格绘制；原始 UV 不变，原画仍使用完整 1254px 画布坐标。网格仅限制要绘制和变形的区域，不裁改 PNG。
- [tail-motion.mjs](tail-motion.mjs) 在原图 `x<=290` 处固定连接区，向尾尖逐渐增加位移。一个周期 6.8 秒，4.6 秒轻摆、2.2 秒休息；尾尖只抬离原落点，不向下穿地。此版本是二维网格形变实验，不是完整猫骨骼或物理尾巴模拟。
- 暂停保持当前帧；幅度为 0 回到原形；网格标出三角形和固定区域参考点；只看尾巴暂时隐藏身体，便于检查变形。
- `pnpm test:meadow` 包含 [cat-tail.test.mjs](../../../scripts/cat-tail.test.mjs)，检查固定连接区、零幅度、休息段、周期连续和网格列不翻折。视觉验收应检查尾根连接、暂停、幅度、网格及花草控件互不影响；纯函数测试不能代替实屏检查。

## 跑步与跳跃

同一个 `#cat-board` 默认自动演示：观察 → 向右跑 → 蓄力起跳 → 落地休息 → 向左跑回 → 休息。静坐时间超过整个循环的一半。按钮可单独触发跑一段、跳一下、坐下休息；暂停保持当前姿势，提供 0.5× / 0.25× 慢放。单次动作结束留在落点，再点动作可继续；尾巴实验仍可单独放大查看。

- [cat-run-v1.png](cat-run-v1.png)：8 个跑步姿势，收腿、伸展和前后脚接触不同。
- [cat-jump-v1.png](cat-jump-v1.png)：站立、蓄力、蹬地、上升、最高点、下降、落地和恢复站立的 8 个姿势。
- 均为 1774 × 887 的 4 列 2 行透明图集，使用内置 ImageGen 参考已确认坐姿生成。首轮姿势靠得太近，再用 ImageGen 调整留白；最终 PNG 原样保存，没有程序重画、抠背景或导出裁切图。完整提示词与两轮来源见 [prompt-actions-v1.json](prompt-actions-v1.json)。
- [cat-atlas.mjs](cat-atlas.mjs) 定义采样矩形和注册点。整组使用同一像素比例，跑步保持共同地平线，让收腿帧的脚真正离地；跳跃腾空姿势按躯干位置校准，不把每帧边界强行缩成相同尺寸。
- [cat-motion.mjs](cat-motion.mjs) 编排动作和位置。跑步按位移推进姿势帧，窄屏缩短步幅但保留一个完整周期；只有跳跃飞行阶段使用抛物线离地。相同时间得到相同姿势，左右跑使用水平镜像，坐姿保持转身后达到的朝向。
- [cat-renderer.js](cat-renderer.js) 使用 WebGL 纹理采样图集中的当前姿势，再应用位移；地面影子随跳跃收缩变淡。跑跳不是坐姿图片整体拉伸，也不是自动生成了完整骨骼。尾巴小动作仍使用原网格。

跑跳使用关键姿势动画；坐站、起跑收步等过渡已按下方流程补齐。不同生成帧的毛发与五官仍有细节差异，后续需要根据实际观感修整一致性。小猫仍只在独立 demo 中。

验证：`pnpm test:meadow` 新增 [cat-actions.test.mjs](../../../scripts/cat-actions.test.mjs)，验证八帧跑姿、完整跳跃阶段、返向、落点、循环、真实 alpha、图集间隔和桌面/窄屏不裁掉主体。用户此前选择自行点击原 demo，未重新授权浏览器任务空间；本轮不自动夺回，动态衔接及控件的实际浏览器验收仍待用户打开查看。

## 关节与骨架观察

`#cat-board` 默认勾选“显示骨架辅助线”，另有“只看骨架”和“拖动看动作”。拖动进度会暂停并保留当前位置，显示当前图集与姿势序号；继续播放后从该进度前进，仍可用原来的慢放按钮。

- [cat-skeleton.mjs](cat-skeleton.mjs) 保存每个姿势的手工近似关节位置，以青绿躯干、橙色前腿、蓝色后腿、紫色尾巴显示连接与节点；头、肩、髋有文字标记。远侧/遮挡侧腿用虚线示意，位置是估计。
- 这层线条帮助观察图片里的肢体变化，**没有绑定或驱动图片**，也不是精确解剖模型。图片换到哪张，标注就切到哪组，不在图片保持同一姿势时伪造关节插值。页面保留同样说明。
- 姿势图与标注共用 [cat-atlas.mjs](cat-atlas.mjs) 的注册点、缩放、镜像和跳跃坐标变换；坐姿图片、尾巴网格与标注统一镜像，保持当前朝向。尾巴标记调用 `deformTailPoint`，跟随实际网格形变，尾根不动。
- “只看尾巴”实验同时限制辅助线范围；“只看骨架”隐藏位图但保留地面参考。关掉骨架后恢复图片并禁用“只看骨架”，不改变动作时间。
- 动作回归新增镜像/离地投影、标注不被修改、坐姿尾巴与网格一致，并检查可见关节标记落在真实图集主体内。浏览器实际观察仍沿用用户自行打开的选择，尚未由 Agent 实屏验收。

## 状态过渡与动作排队

用户指出坐下到奔跑等状态缺少衔接，因此新增四张 1774 × 887、4 列 2 行的透明图集：

| 文件                                     | 用途                                       |
| ---------------------------------------- | ------------------------------------------ |
| [cat-rise-v1.png](cat-rise-v1.png)       | 坐下到站立的八个姿势；反向播放用于收腿坐下 |
| [cat-gait-v1.png](cat-gait-v1.png)       | 上排迈步起跑，下排减速收步                 |
| [cat-prepare-v1.png](cat-prepare-v1.png) | 上排跳前下蹲，下排落地恢复                 |
| [cat-turn-v1.png](cat-turn-v1.png)       | 站姿从朝右经过正面小步转向朝左             |

由内置 ImageGen 参考已有猫图生成；坐站、准备和转身图再生成修正留白。最终 PNG 原样保存，完整提示词、修正词和来源在 [prompt-transitions-v1.json](prompt-transitions-v1.json)。运行时记录各帧注册点，并为每张图集设一个固定比例；不逐帧按包围盒改变体型，不导出裁切图。

播放时，过渡两端复用已有坐姿、站姿、跑步接触姿势和跳跃姿势；新图集提供中间帧，避免每组各画一张不同的“站姿”。动作路径是坐下 → 收尾巴 → 起身 → 站稳 → 起跑 → 跑动 → 收步 → 站稳 → 坐下；跳跃经过下蹲、蹬地、飞行、落地、恢复站立。方向改变先播放转身，再使用对应朝向的图像。

[cat-motion.mjs](cat-motion.mjs) 只允许从坐稳或站稳的状态建立后续动作。`nextCatSwitchTime` 找下一个安全节点；[cat-board.js](cat-board.js) 将最新按钮请求排队，到达节点才开始，并继承位置、朝向、观察距离和尾巴幅度。空中请求必须完成落地恢复，跑动请求会完成当前跑段并收步；界面显示“接着…”提示。拖动进度取消排队并暂停，暂停后继续保留当前帧。自动演示回到起点的前缀只运行一次，后续循环不会传送。

尾巴使用独立累计时间，避免换模式时摆动相位重置；起身前先平缓收回尾巴，坐下后逐渐恢复轻摆。尾巴实验的观察距离也用短过渡改变。新增姿势的人工辅助线在 [cat-transition-skeletons.mjs](cat-transition-skeletons.mjs)，仍是逐帧说明，不驱动图片。

决策见 [ADR-0008](../../../docs/decisions/0008-cat-action-transitions.md)。回归覆盖过渡顺序、起跑/收步位置与速度连续、尾巴与观察距离边界、任意时间请求的安全接续、飞行不可中断、循环前缀、六张图集 alpha/留白/标注和窄屏边界。数据通过不等于视觉验收：生成帧仍可能有五官、毛发与重心的细微跳变，需在原 demo 慢放检查。用户继续自行打开页面，Agent 未重新接管浏览器。
