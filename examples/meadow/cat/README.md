# 草甸小猫 · 造型初稿

[cat-idle-v1.png](cat-idle-v1.png) 是按用户提供的猫照片生成的第一版透明坐姿原画。使用内置 ImageGen，保留生成结果与 alpha；[完整提示词及来源](prompt-v1.json) 可追溯。

照片作为脸部与毛色参考：奶白短毛、圆脸、淡粉耳内和照片光线下的深蓝灰眼睛。照片未完整展示的脚与尾巴按可见体型补全，因此这些部位是设计推演。画面笔触、明暗色块与光线参考既有白雏菊素材。私人原始照片不复制进仓库。

已选行为方向是自然小猫：以观察、蹲伏、甩尾为主，偶尔跑跳。当前包含静态原画、身体/尾巴两张分层初稿，以及同页独立 Canvas 的尾尖摆动实验；尚未制作跑跳动作或接入首页。

运行 `pnpm demo:meadow`，在原花草比较页的素材区查看小猫卡片：<http://localhost:55022/#cat-sample>。小猫与三张花草姿态素材并排展示，点击可打开透明原图；没有新增独立页面，也没有加入花草动画场景。

验证：检查全身轮廓、脸部相似度与画风，并解码确认有真实透明像素和接近不透明的主体。浏览器检查同页卡片加载、窄屏布局和原有草甸场景正常。

## 身体与尾巴分层初稿

- [body-no-tail-v1.png](body-no-tail-v1.png)：移除尾巴，补画原来被遮挡的后腿、脚和身体底部；头、躯干和前腿保持同一坐姿。
- [tail-v1.png](tail-v1.png)：独立弯曲尾巴；首轮生成的尾根有尖角，第二次局部编辑修整为较圆的轮廓。
- 两张文件均为 1254 × 1254 透明 PNG，保留原画坐标及生成结果的 alpha，未用程序裁切或重画像素。生成补画不等于逐像素无损分割，尾巴轮廓和毛发细节会与原图略有变化。
- 生成方式为内置 ImageGen，完整首轮与修正提示词、生成文件名见 [prompt-layers-v1.json](prompt-layers-v1.json)。
- 同页查看 <http://localhost:55022/#cat-layers>：身体、放大的尾巴局部和两张图片按同尺寸同坐标叠合的对照。尾巴缩略图使用 SVG viewBox 查看局部，文件本身仍是完整画布；叠合区域使用两个原始 PNG，不能按各自内容边界独立居中。
- 两张素材已接入下方所述网格摆动实验；用户选择自行打开 demo，浏览器画面和动态接缝仍需实际查看。

## 独立尾巴动画板

入口仍在同一页面：<http://localhost:55022/#cat-board>。猫使用自己的 WebGL Canvas、网格叠加 Canvas 与控件，不进入花草场景，也不共享其播放状态。

- [cat-board.js](cat-board.js) 负责暂停、幅度、网格、只看尾巴、ResizeObserver、屏外与后台暂停；减少动态效果时默认静止。资源或 WebGL 失败时回退到两张 PNG 的静态叠合。
- [cat-renderer.js](cat-renderer.js) 静态绘制完整身体，尾巴用 19 × 9 顶点的局部矩形网格绘制；原始 UV 不变，原画仍使用完整 1254px 画布坐标。网格仅限制要绘制和变形的区域，不裁改 PNG。
- [tail-motion.mjs](tail-motion.mjs) 在原图 `x<=290` 处固定连接区，向尾尖逐渐增加位移。一个周期 6.8 秒，4.6 秒轻摆、2.2 秒休息；尾尖只抬离原落点，不向下穿地。此版本是二维网格形变实验，不是完整猫骨骼或物理尾巴模拟。
- 暂停保持当前帧；幅度为 0 回到原形；网格标出三角形和固定区域参考点；只看尾巴暂时隐藏身体，便于检查变形。
- `pnpm test:meadow` 包含 [cat-tail.test.mjs](../../../scripts/cat-tail.test.mjs)，检查固定连接区、零幅度、休息段、周期连续和网格列不翻折。视觉验收应检查尾根连接、暂停、幅度、网格及花草控件互不影响；纯函数测试不能代替实屏检查。
