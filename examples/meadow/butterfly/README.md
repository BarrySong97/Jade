# 手绘蝴蝶 · 振翅与飞行

原花草 demo 的独立画布：<http://localhost:55022/#butterfly-board>。运行 `pnpm demo:meadow`；已有页面需要刷新，新增工具类后预览服务需重启。

用户已选择让猫半藏在草里，并要求整合前先生成蝴蝶动画。本轮为暖杏黄色蝴蝶的独立预览；猫、花草及首页的状态不被它控制。

## 原画与来源

- [butterfly-wingbeat-v1.png](butterfly-wingbeat-v1.png)：1774 × 887，4 列 2 行，八个开合姿势。头朝上，身体保持同一视角，翅膀依次展开、抬起、竖起合拢、再展开。
- 使用内置 ImageGen，参考现有黄色野花与侧向白花的手绘明暗、笔触和柔和颜色；原图只有蝴蝶，没有把花草画进图集。
- 首版部分翼尖太靠近采样边界，再用 ImageGen 缩小并增加留白。最终 PNG 原样复制，保留真实 alpha；完整生成与修正提示词、来源见 [prompt-wingbeat-v1.json](prompt-wingbeat-v1.json)。未程序重画、抠背景或导出裁切图片。

## 动画

[butterfly-motion.mjs](butterfly-motion.mjs) 保存采样区与身体注册点，全部姿势使用同一个比例。每 0.32 秒播放一轮八个姿势，作为当前预览的视觉节奏；不是物种翅频测量。图集提供真实的翅膀姿势变化，程序没有把整只蝴蝶横向压扁来替代振翅。

飞行由 16 秒连续曲线控制，叠加频率不同的横纵起伏；首尾位置及切线连续，身体随横向运动轻微倾斜。它是可重复的预览轨迹，未加入花头停驻、猫追逐或鼠标跟随。

[butterfly-board.js](butterfly-board.js) 用 Canvas 2D 在运行时采样 PNG。支持自在飞行、原地放大振翅、暂停、0.5× / 0.25× 慢放及可选轨迹；当前姿势序号仅视觉更新，不连续播报。原地观察通过 0.65 秒平滑改变位置、尺寸和倾斜，不重置翅膀或飞行相位；中途反向切换继承当时的观察比例。

按视口调整蝴蝶大小及活动范围，屏外、后台或页面离开时停表，恢复后延续时间。偏好减少动态效果时默认暂停，主动点动作/播放才动；最终离开页面时移除监听器与观察器。资源或 Canvas 失败会显示原画回退；SVG 仅作为原 PNG 首格的静态观察窗口，不重画翅膀。

## 验证与限制

[butterfly.test.mjs](../../../scripts/butterfly.test.mjs) 已加入 `pnpm test:meadow`：八姿势及相位、飞行首尾连续、原地注册点、观察过渡中途反向；解码真实 PNG 检查尺寸、透明背景、留白、身体注册点、开合宽度差，以及 240/335/375/1327px 画布中主体不裁切。

纯函数和 PNG 检查不能替代浏览器验收。需要实看振翅节奏、笔触帧间变化、放大时身体是否稳定、暂停/慢放、屏外暂停与猫及花草控件独立。延续用户自行打开原 demo 的选择，Agent 不自动重新接管浏览器。
