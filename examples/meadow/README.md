# 花与草 · 完整组合预览

运行 `pnpm demo:meadow`，打开 <http://localhost:55022>。预览服务只监听本机，`Ctrl+C` 停止。需要已安装项目依赖，无新增依赖。

修改页面或脚本后需刷新浏览器；仅跳转到另一个 `#场景` 不会重新加载代码。新增 Tailwind 工具类后需重启预览服务，再刷新页面。

完整追蝶场景在 <http://localhost:55022/#chase-scene>：猫半藏在草里探头，等蝴蝶落花后伏低观察 1–2 秒，再跑起来扑跳；蝴蝶绕开，猫回另一侧草丛。共用时钟、花头停驻与新动作素材见 [追蝶说明](chase/README.md)。提供暂停、慢放和当前轮进度；下方独立画板继续保留。

小猫的照片参考坐姿初稿放在本页素材区，与三张花草姿态素材并排展示；可直接打开 <http://localhost:55022/#cat-sample>。点击卡片查看透明原图，来源见 [小猫素材说明](cat/README.md)。

同页新增身体/尾巴分层初稿和静态叠合对照，入口 <http://localhost:55022/#cat-layers>。两张原画共用 1254px 方形画布，叠合时保留同一坐标。

独立小猫动画板位于 <http://localhost:55022/#cat-board>，使用自己的 Canvas 和控件：默认自动演示观察、跑动、跳跃、落地休息及折返，也可单独触发跑一段、跳一下、休息和尾巴实验。提供暂停与慢放；尾巴实验仍可调幅度、看网格或只看尾巴，不改变花草画布。跑跳使用两组姿势图集，另有坐站、起跑收步、跳跃准备恢复和转身四组过渡；动作途中点击按钮会排队到坐稳/站稳再执行。技术边界与验收见 [小猫说明](cat/README.md)。

小猫画布默认叠加彩色关节辅助线，可选“只看骨架”并拖动进度暂停观察。这些线条是逐姿势人工标注，帮助理解四肢变化，并未驱动 PNG；尾巴标记跟随实际网格形变。

蝴蝶独立画布在 <http://localhost:55022/#butterfly-board>：暖杏黄色手绘 PNG 的八个振翅姿势，配连续起伏飞行路线。可切换原地放大观察、暂停、慢放或查看轨迹；控制与猫、花草分开。原始图集、提示词、播放原理和限制见 [蝴蝶说明](butterfly/README.md)。

默认入口为 I 自然生长的草甸（`#wild-meadow`），沿用用户照片的草多、小花、白黄与蓝紫配色，再按用户要求降低约 10% 的排布密度。总株数取旧版相同视口的 90% 并四舍五入；桌面 1327px 画布从 161 株减少到 145 株，333px 窄屏从 62 株减少到 56 株。视觉覆盖面积还取决于素材轮廓与遮挡，不等同于株数比例。

[natural-meadow.mjs](natural-meadow.mjs) 用固定种子的随机数生成大小、中心间距不同的松散群落；同种花局部聚集，混入少量其他花和散株。草叶按连续密度场穿插；根部深度、花株高度、素材与镜像分别变化。随机排布只在布局时计算，动画帧不会重新抽样。新增两种草叶轮廓与一种侧向白花减少素材内部的重复；无穗草按叶片尺度缩小，避免按带高穗的全株高度放大。

上一版照片参考草甸保留为 I₀（`#wild-meadow-v1`），放在折叠对照区，与新版本比较密度与排布。照片用于植物比例、密度和配色参考；保留原有手绘笔触。

同列保留三种混种场景：F 自然混种（7 种花）、G 繁花草甸（全部 11 种花）、H 疏朗花间（6 种花）。点击卡片切换可动大图，页面下方查看每张独立素材；对应链接为 `#mixed-natural`、`#mixed-full`、`#mixed-airy`。复用既有 PNG，将粉、白、蓝紫与暖黄混合，高花与低花分两层错开落点，变化高度和间距，较矮花株后绘制，避免花头被大株叶片遮住。

折叠区同时保留之前的五种场景：A 林间白蓝、B 粉色野花、C 紫色花境、D 春日花园、E 原版花草。旧链接 `#woodland`、`#blush`、`#violet`、`#garden`、`#original` 仍可直接打开对应场景并展开对照区。第一版单场景页面保留在 <http://localhost:55022/original>。

## 组合与动作

- [meadow.js](meadow.js) 按后层高草、低草、花株、前层小草绘制。高度、间距与镜像不同，使用确定性排布；手机上调整尺寸和数量。
- [renderer.js](renderer.js) 在同一个 WebGL canvas 上绘制所有植物，每种加载的素材只上传一次纹理，共享一个 3 × 9 顶点网格。每株拥有自己的摆动相位和幅度，花比草摆得轻。
- 每株保持底部整行不动，上方按 `bend × h²` 横向位移。原图不变，纹理坐标不变，GPU 将原图采样到变形的三角形上。
- 预览支持暂停、风力、网格显示。网格只标注部分代表植物，以便看清单株结构。风力为零、页面不可见或草坪离开视口时停止动画帧；偏好减少动态效果时默认静止。
- 画布底部遮住植物收束的根尖，前后层低草连接成连续边缘。该画布是固定视角的二维组合。

选定自然草甸已接入博客首页最底部，位于 Footer 后，保持全宽铺开与微风；生产页不包含预览控件。首页将实际使用的 11 张原画压缩为 WebP，原始 PNG 留在此处便于追溯和继续设计。`renderer.js` 和 `natural-meadow.mjs` 分别导出 `src/components/home/meadow-renderer.js` 与 `src/lib/meadow-layout.mjs` 的共享实现，预览服务为它们提供明确路由。

猫蝶追逐保留在同页 demo。用户最终决定首页只加入杏黄与蓝紫两只蝴蝶，见 [蝴蝶素材说明](butterfly/README.md)。当前花草整株摆动，未拆独立花瓣和每片叶子。大幅度风动会拉伸原画，因此默认微风。首页生命周期、静态回退与边界见 [组件模块](../../docs/modules/components/README.md)、[ADR-0006](../../docs/decisions/0006-home-meadow.md) 和 [ADR-0010](../../docs/decisions/0010-home-butterflies.md)。

## 文件与验证

[index.html](index.html) 使用 Tailwind 工具类完成布局；[preview.mjs](preview.mjs) 在内存中编译样式，只允许明确列出的资源路径。

验收项目：十六张原图解码与真实 alpha、自然草甸/上一版/历史场景切换及原图入口、新素材实际用于场景、同视口株数为上一版的 90%（四舍五入）、固定种子排布稳定、缩略图与大图使用相同素材、折叠区展开后缩略图正确绘制、微风连续变化、暂停后时间固定、零风力回到原形、网格开关、手机无水平溢出、减少动态效果时静止。仓库验证沿用 `pnpm build`、`pnpm check` 和 `node scripts/check-docs.mjs`。
