# 海风与远行 · 独立 Demo

运行 `pnpm demo:harbor`，打开 <http://localhost:55025>。仅监听本机，Demo 控件不进入生产页面。用户确认后工业海港已接入 `/about` 页尾，场景纯逻辑和渲染器提取到 `src/` 共同使用；以下版本描述保留迭代历史。

## 制作方式

当前工业版：现代吊机、集装箱、仓库与混凝土码头，货船沿固定水线向右直航、不缩小；在建钢船前有三位安全帽工人，携工具走向作业点、停下施工、走回休息。新素材 `assets/industrial-{harbor,boat,yard,workers}-v1.png` 由内置 ImageGen 生成，PNG 原样保留，WebP 仅缩放压缩；[完整提示词](prompts-industrial.json)。下面旧木船版本说明仅记录迭代历史。

沿用 Codex 会话 `01a0b827-c628-7a03-a6a2-9d6ec84766f6`（2026-09-19）和 [草甸原型](../meadow/README.md) 的「透明原画＋轻动画」路线。三渲二指手绘体积色块的视觉风格，这里没有运行时 3D 模型。

- `assets/harbor-v1.png`：左侧石砌港口、中央开阔海面、右侧低矮海岸，背景静止。
- `assets/boat-v1.png`：独立帆船，用水线注册点定位，64 秒一轮，向右上远海移动、逐渐缩小、轻微摇晃并在远处渐隐；不可见阶段回到港口。
- `assets/gull-wingbeat-v2.png`：八姿势透明图集，三只海鸥不同周期飞行，两次振翅后滑翔。按肩部手工注册，非真实骨骼动画。v1 翼尖靠近格边，保留历史但不被页面加载；v2 重新生成安全留白并纳入测试。
- 原 PNG 均由内置 ImageGen 生成并原样复制；[完整提示词](prompts.json) 与 [图集修正提示词](prompt-gull-v2.json) 保存参考与生成源。WebP 仅用 sharp 缩小压缩，不修改原画；Canvas 合成图层、轻微尾流与姿态，不重新绘制港口/船/鸟。

## 文件

当前第三版为页脚通栏：场景是页面最后一个元素，桌面 240px / 手机 176px，无底部外边距；两岸按最多 660px 原画尺度等比缩小，中部海面延展到视口两端，并使用原画海水铺底覆盖透明收边。船最大 66px、船坞约 119px，人物随船坞缩小；控件与原画区均置于海景之前。不改原始素材、不接入 About。

第二版将出航船放大约六成，并向港口右侧让出航线；左岸新增固定干船坞、露出肋骨的在建木船和三位错峰敲击/休息的工人。人物使用四姿势图集、脚底固定，尚不模拟船体逐步完工。新增原画为 `assets/shipyard-v1.png`、`assets/workers-v1.png`，由内置 ImageGen 生成；[完整提示词](prompts-shipyard.json) 可追溯，原始 PNG 保留，WebP 只做缩放压缩。

- `scene.mjs`：航行、响应式几何与图集注册点纯函数。
- `harbor.js`：Canvas 2D 渲染及播放状态。暂停、0.5×、重新出航、航程拖动；后台和屏外停表，减少动态效果默认静止。加载失败保留静态海港，按钮禁用。
- `preview.mjs`：沿用草甸 Tailwind 内存编译与固定路径白名单。新增工具类后重启服务。
