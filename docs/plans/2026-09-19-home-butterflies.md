# 首页双蝴蝶

用户已决定首页不放猫，要求把蝴蝶接入首页草甸，再加一只不同颜色的蝴蝶。保留暖杏黄色，新增蓝紫色；猫与追逐实验留在 demo。

1. 用内置 ImageGen 制作蓝紫色振翅、落花/起飞图集，保存原 PNG 和提示词。
2. 首页仅加载两色蝴蝶与现有花草，使用原 WebGL 渲染器和统一生命周期；双方各自飞行、错开停驻与振翅，停驻跟随真实花头。
3. 构建期将图集压缩为 WebP；静态回退显示两只蝴蝶，减少动态效果、屏外、后台均停止计时，离页释放资源。
4. 增加色彩/透明度、路径边界/停驻贴合和首页隔离回归，更新模块与架构文档，执行 build、check、check-docs 和本机页面资源检查。

延续用户自行打开页面的选择，不重新接管浏览器；实际页面视觉验收状态如实说明。

## 实施结果

首页已接入杏黄与蓝紫两只蝴蝶，静态回退同样显示两只；猫与追逐继续留在 demo。蓝紫两张图集与生成提示词已保存，原文件与生成源字节一致。

`pnpm build` 生成 50 页；`pnpm check` 通过（7 项 hook、32 项动画/边界回归，6 条原有 unused 警告），`check-docs` 0 ❌。四张生产 WebP 共 389,768 字节，1024×512 并保留 alpha。只读检查确认首页有两只静态蝴蝶、其他 49 页无草甸挂载、生产目录无猫素材，原 demo 的 21 个递归模块全部可加载。

本机首页预览为 `http://localhost:4321/#home-meadow`；旧 demo 为 55022。浏览器实屏验收未执行，保留用户自行查看的方式。
