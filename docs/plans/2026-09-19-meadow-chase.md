# 草丛中的小猫与蝴蝶

用户已批准并要求实施：蝴蝶先飞，小猫从草中探头；蝴蝶落花后小猫伏低盯住 1–2 秒，随后起跑接扑跳；蝴蝶绕开，小猫落地回到草边，再开始下一轮。猫半藏在草中，固定镜头，继续手绘姿势图路线。

## 实施

1. ImageGen 补猫伏低/探头、伏低起跑/跑动扑跳、蝴蝶收翅停驻/起飞三个透明图集，保存原图和完整提示词，沿用现有跑跳与转身素材。
2. 在原花草 demo 增加完整追蝶场景，复用自然草甸排布与 PNG。使用一个 WebGL 画布按后景花草、猫、前景遮挡、蝴蝶顺序绘制，统一时钟；单独动作画板保留。
3. 确定性剧情控制双方状态：探头、落花、伏低等待、起跑、连续扑跳、避让、落地恢复、移动回草边、转身伏低。每轮换花与方向，位置和姿势在边界连续。
4. 落花点按原图花心坐标注册，使用与花株相同的风动投影；等待必须在猫与蝴蝶就位后计时，逃离由猫接近目标触发。
5. 原页面提供暂停、慢放、进度观察；减少动态效果默认暂停，屏外/后台停表，资源失败保留静态草甸。

## 验证

生成 PNG 真实透明/间隔/注册点、过渡顺序、等待时长、猫与蝴蝶接近事件、停驻随花摇、无瞬移的循环及窄屏范围。更新模块文档与 ADR，执行 build、check、check-docs，检查 HTTP 资源。延续用户自行打开原 demo 的选择，未完成的浏览器实屏验收如实说明。

本轮交付完整场景预览；首页现有草甸的合入以这次场景效果确认后继续。

## 实施结果

三张原始图集与提示词已保存，完整场景入口为原 demo 的 `#chase-scene`。猫左右交替追逐白雏菊/黄色野花上的蝴蝶；六轮组合改变等待时长，旧独立画板继续保留。

已通过 7 项 hook + 26 项草甸/猫/蝶测试，`pnpm build` 生成 50 页，`pnpm check` 无错误（保留 6 条原有 unused 警告），`check-docs` 0 ❌。本机服务已重启；只读 HTTP 检查覆盖当前页面、75 个唯一 ID、12 个递归模块、20 张 PNG、样式和白名单限制。新 PNG 与生成源文件字节一致。

实屏动画与控件验收未执行：延续用户自行打开原页的选择，没有重开浏览器任务。程序测试已覆盖位置/倾斜连续、真实 alpha 范围、花头贴合和前草遮挡，生成姿势的毛发/体型接缝仍需看实际播放效果。
