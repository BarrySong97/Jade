# 更多花型与场景对比

- 日期：2026-09-19
- 授权：用户要求把已讨论的花型都生成，并组合成多种场景直接看效果。

## 方案

保持 C 版手绘色块与固定视角，新增八种独立透明 PNG：铃兰、风铃草、勿忘草、波斯菊、耧斗菜、鸢尾、虞美人、郁金香。现有草与花继续复用。扩展花草预览为五个可切换场景，所有新花至少用于一个场景；原版保留作为参照。

1. 林间白蓝：铃兰、勿忘草、风铃草，花较少，草较疏。
2. 粉色野花：波斯菊、虞美人，穿插少量原版雏菊。
3. 紫色花境：耧斗菜、鸢尾、风铃草，凸显不同的花瓣轮廓。
4. 春日花园：郁金香、波斯菊、勿忘草，较低且有层次的组合。
5. 原版花草：保留第一版花草作为对照。
