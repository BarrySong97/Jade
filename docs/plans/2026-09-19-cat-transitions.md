# 小猫动作状态衔接

用户认可逐帧动画，要求生成并接入坐姿、跑动、跳跃等状态之间的过渡。此要求即本轮实施授权。

## 实现范围

1. 参考现有坐姿、跑姿、站立/跳跃图集，用内置 ImageGen 补坐站、起跑/收步、跳前下蹲/落地恢复、转身图集；保存原 PNG 与完整提示词。
2. 用既有坐姿与站姿作为精确端点，新增姿势填充中间段；站稳作为动作衔接节点，跑步退出时完成一个步态周期。
3. 动作请求排队到站稳/坐稳再执行；腾空不能被突然改成坐姿。自动演示、单次按钮、暂停和进度拖动共用一条状态时间线。
4. 保留骨架辅助标注的说明与观察功能，为新增姿势补标注；方向变化使用转身帧，坐姿和图层统一镜像。

## 验证

- 真 PNG 解码检查透明、留白、注册点及可见关节标注。
- 纯函数验证过渡顺序、运动连续、安全切换、飞行中排队、循环与视口边界；跑 build、check、check-docs。
- 原 demo 同页更新，延续用户自行打开的选择；未经授权不重新接管浏览器，实际视觉验收如未完成必须说明。
