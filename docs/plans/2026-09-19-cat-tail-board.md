# 独立小猫 Canvas 动画板

- 用户授权：先让生成的小猫动起来，放在独立于花草画布的 Canvas board 中；延续同一 demo 页面，无需另开页面。
- 本轮只验证已拆出的身体与尾巴：身体固定、尾根固定、尾尖轻摆。没有跑跳、头部或眼睛素材，不模拟这些动作。

## 实现

- 在原花草 demo 加入独立 `cat-board` 区域、WebGL Canvas、网格叠加及其专属控件。使用原有二维网页技术，不创建视频工程。
- 两张原始 1254px PNG 共用同一坐标，身体四边形静态绘制，尾巴使用局部细分网格；尾根区域保持零位移，摆动逐渐传到尾尖。
- 提供暂停、幅度、网格和只看尾巴；屏外/后台停止帧，减少动态效果时默认暂停。无 WebGL 时保留静态叠图。
- 独立脚本与状态不影响现有花草场景；本地服务只增加确切的模块路径。

## 验证

- 纯动作函数：根部固定、零幅度保持原形、时间变化作用于尾尖、位移有界、休息段静止。
- 页面与素材路由、构建、已有回归、文档检查。
- 浏览器画面与控件需要实看；用户此前选择自行打开原 demo，本轮不自行夺回已结束的浏览器任务空间。

## 结果

- 已加入独立猫 WebGL Canvas 与网格 Canvas，具备暂停、幅度、网格及只看尾巴；花草脚本与控件保持独立。
- 3 项猫尾巴动作回归通过，原 3 项草甸及 7 项 Stop hook 回归通过。HTTP 验证所有模块和素材返回 200、控件 ID 唯一、画布高度样式存在、未列入白名单的文件仍返回 404。
- `pnpm build`、`pnpm check`、`node scripts/check-docs.mjs` 通过；oxlint 保留既有 6 条未使用变量警告，无新增错误或警告。
- 尚未完成浏览器实屏验收；链接为 `http://localhost:55022/#cat-board`，用户沿用自行打开的选择。
