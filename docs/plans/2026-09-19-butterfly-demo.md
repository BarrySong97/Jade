# 蝴蝶振翅与飞行预览

用户已选定小猫半藏在草丛里，要求在合入草丛之前先生成蝴蝶动画。本轮先制作并在原花草 demo 展示，按当前指令直接实施；猫与草丛的整合留待这次预览后讨论。

## 范围

1. 用内置 ImageGen 参考现有花草的手绘笔触，生成一只暖杏黄色蝴蝶的透明振翅图集；保持身体位置和花纹一致，完整循环开合。
2. 将原始 PNG 与完整提示词保存到 `examples/meadow/butterfly/`，运行时采样，不程序重画像素。
3. 在原 `variations.html` 添加独立蝴蝶 Canvas：自在飞行、原地看振翅、暂停、慢放、可选轨迹。控制和生命周期与猫及花草隔离。
4. 纯函数控制连续轨迹与帧序列；在原地观察与飞行之间平滑改变位置和大小，保留振翅相位。支持窄屏、减少动态效果、后台/屏外停表与静态回退。

## 验证与交付

- 检查真实 alpha、图集间隔、固定身体注册点、循环和视口边界；必要的确定性回归接入 `pnpm check`。
- 更新示例与脚本模块文档，执行 build、check、check-docs，重启预览并检查页面资源。
- 延续用户自行打开原 demo 的选择，不自动接管浏览器；如实说明尚未完成的实屏验收。
