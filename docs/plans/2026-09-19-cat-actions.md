# 独立猫画布：跑步与跳跃

用户已明确要求让小猫跑起来、跳起来，并在原花草 demo 的独立 Canvas 中查看，按此范围执行。

## 实现

1. 以已确认的奶白猫为参考，用内置 ImageGen 生成透明跑步、跳跃姿势图集，保留原图和完整提示词。
2. 以同一尺寸及落脚点注册姿势；跑步播放收腿、伸腿帧，跳跃播放蓄力、蹬地、腾空、落地帧。动作纯函数控制时间与位移，避免把坐姿平移冒充跑步。
3. 同一独立画布提供自动演示、跑一段、跳一下、休息、暂停、慢放；保留尾巴网格实验。所有状态独立于花草画布。
4. 屏外/后台暂停、减少动态效果默认暂停、错误静态回退。保持首页与展示页边界。

## 验收

- 检查原图透明通道、姿势排列和轮廓，记录生成帧仍可能存在的细节差异。
- 纯函数测试覆盖落地高度、方向、循环连续、视口边界与动作完成，运行 build / check / check-docs。
- 在原 demo 提供同页入口；尊重用户自行打开页面的选择，不自动夺回浏览器任务空间。若未实际操作浏览器，明确记录实屏验证待完成。

## 结果

- 两张 1774×887 透明图集已保存，共 8 帧跑姿与 8 个跳跃姿势；首轮间距修正、提示词及注册点可追溯。
- 原独立画布默认自动演示，提供跑一段、跳一下、坐下休息、尾巴实验、暂停和 0.5× / 0.25× 慢放。单次动作完成保留落点，自动演示含折返与较长休息。
- `pnpm check` 通过：7 项 Stop hook 回归 + 10 项草甸/猫动作回归；oxlint 无错误，仅保留原有 6 条未使用变量警告。
- `pnpm build` 成功构建 50 页；`node scripts/check-docs.mjs` 为 0 ❌。HTTP 检查所有猫动画模块与素材返回 200，按钮/ID/样式齐全，非白名单资源为 404。
- 预览已在原端口重启：<http://localhost:55022/#cat-board>。本轮尚未实际操作浏览器；用户自行查看的选择继续生效。坐站关键姿势切换和生成帧细节差异需实屏评估，不能把资源/动作测试当成视觉验收。
