# 草甸疏密与自然群落

- 授权：用户先要求整体密度降低约 10%、增强随机性，随后讨论自然生长规律，现确认先制作草丛。
- 范围：更新野花草甸预览，保留旧版对照；猫与蝴蝶后续制作。

## 已确认的方向

保持固定视角、独立透明 PNG 与手绘色块风格。减少等间距分段，采用大小和间距不同的松散群落、同种花局部聚集、花少而草多的过渡。总株数按旧版相同视口的 90% 控制；这表示排布密度，视觉覆盖率还需浏览器检视。

## 实施

- [x] 生成两种不同轮廓的细草和一种白花姿态变体，原样保留 alpha 与完整提示词。
- [x] 以固定种子生成不规则群落，按连续密度变化分布草叶，花簇混入少量散株。
- [x] 根部前后错开，同种花共享群落但变换高度与姿态；保留旧版用于对照。
- [x] 浏览器检查桌面/窄屏的密度、重复感、遮挡和动画；验证株数比与确定性。
- [x] 更新模块与素材文档，运行 build/check/check-docs，按规范提交。

## 验证记录

- 三张生成 PNG 有全透明区域和主体高 alpha 像素，原样保存；最大 alpha 为 254 的图片通过主体像素检查，不误判为不透明主体缺失。
- 排布断言：1327px 为 161 → 145 株，960px 为 126 → 113 株，333px 为 62 → 56 株；均等于旧版 90% 四舍五入。固定种子重复计算结果相同，所有坐标有限、素材有效，三张新增素材均使用。
- 桌面与 390px 浏览器实看；窄屏无横向溢出，WebGL 错误码为 0，切换新旧场景保留暂停时间，10 张场景缩略图完成绘制。
- 缩略图与大图统一实际视口尺寸，避免群落数量随宽度变化后预览成了另一套排布。
- `pnpm build`、`pnpm check` 与文档检查通过；保留仓库原有 6 条未使用变量警告，本模块独立 oxlint 无警告。
