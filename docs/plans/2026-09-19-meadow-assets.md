# 花草素材与完整组合预览

- 日期：2026-09-19
- 授权依据：用户已选定 C 版手绘体积感、固定视角的二维素材路线，并在看过 PNG 网格动画后要求「开始生成完整的」，随后补充「先生成花和草」；蝴蝶为后续步骤。

## 方案

沿用选定的 C 版色彩与笔触，用内置 ImageGen 分别生成低草、高草、白雏菊、淡紫花、黄色小花，保留真实透明通道。每种植物是独立 PNG，可在网站页脚场景中重复排列并用二维网格独立弯曲。本步交付素材和完整花草带的交互预览，供继续讨论最终布局。

## 文件与边界

- `examples/meadow/assets/`：生成素材原文件，版本与提示词可追溯。
- `examples/meadow/`：完整花草组合、素材预览及动画控制；复用项目现有 Tailwind，无新增运行时依赖。
- `docs/modules/examples/README.md`：记录新预览及验证方式。
- `package.json`：增加本地预览入口。
