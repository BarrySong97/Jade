# 首页底部草甸

- 用户授权：将选定草甸加入博客首页，且只在首页、页面最底部显示；延续最初预览中横向铺开的感觉。
- 保持最新自然群落排布和微风，去除预览界面；猫与蝴蝶不在本轮范围。

## 方案

- BaseLayout 在 Footer 后增加可选 `page-end` 插槽，只有首页传入草甸组件。文章和独立展示页保持隔离。
- 提取预览已验证的 WebGL 渲染器与自然排布为共享模块；预览继续调用同一真源。
- Astro 构建期只优化实际使用的 11 张透明原画为 WebP，提供静态植物组合；接近视口后初始化动画。
- 自定义元素管理加载、ResizeObserver、IntersectionObserver、减少动态效果和换页清理，不增加动画依赖。
- 浏览器验证首页全宽底边、窄屏、动画及静止模式、首页与文章往返；构建产物检查只有首页出现草甸。

## 验收

- [x] 首页 Footer 后全宽显示草甸；不遮挡正文或版权链接。
- [x] 其他页面没有草甸元素和素材引用。
- [x] 动画仅可见时运行；减少动态效果时静止，WebGL 上下文丢失时切回静态装饰；换页释放资源。
- [x] 共享排布维持已选版，旧预览仍可运行。
- [x] 文档与 ADR 同步，build、浏览器、check-docs、check 通过。

## 验证记录

- 生产预览桌面 1440 × 1100、手机 390 × 844：草甸贴页面底部，无横向溢出。
- 站内链接进入文章后草甸为 0，旧元素断开并清理；返回首页后恢复动画。
- 减少动态效果时 `motion=paused`、弯曲量为 0；滚出视口暂停；模拟 WebGL 上下文丢失后仍显示静态花草。
- 构建 50 个页面，只有 `index.html` 引用草甸及其素材；11 张 WebP 合计约 658 KiB。
- 原预览默认场景正确绘制 145 株；排布、页面边界共 3 项回归及 7 项 Stop hook 回归通过。
- `pnpm build`、`pnpm check`、`node scripts/check-docs.mjs` 通过。oxlint 保留 6 条既有未使用变量警告，无错误或本轮新增警告。
