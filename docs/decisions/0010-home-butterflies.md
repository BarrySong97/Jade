# ADR-0010：首页草甸只接入两色蝴蝶，不接入猫

- 状态：采纳
- 日期：2026-09-19

## 背景

用户看过追蝶场景后决定首页不放猫，要求保留蝴蝶并增加另一种颜色。首页仍保持固定视角、自然花草与克制的装饰，不需要 demo 的剧情或控件。

## 决定

首页保留暖杏黄蝴蝶，新增 ImageGen 生成的蓝紫色振翅与落花图集。只导入花草和四张蝴蝶 PNG，猫、追逐时间线、骨架与 demo 控件留在独立示例。生产纯逻辑位于 `src/lib/`，客户端不依赖示例脚本。

使用已有 WebGL 上下文，在花草之后绘制两只图集蝴蝶，无新增运行依赖或第二条动画帧循环。`meadow-wind.mjs` 统一风动与网格内插值；蝴蝶在选定真实花头停驻，落花时脚部随花摇。两只的飞行路线、振翅频率和 29/37 秒周期不同，候选花株分开；全局飞行时间不在周期切换时重置。

构建期将四张图集缩至 1024×512 的透明 WebP（quality 88）；静态回退显示两色蝴蝶，后续渐进增强。延续 ADR-0006 的首页独有挂载、屏外/后台暂停、减少动态效果静止及 ClientRouter 清理。

## 可执行约束与限制

[home-butterflies.test.mjs](../../scripts/home-butterflies.test.mjs) 纳入 `pnpm check`，以 ADR 编号约束首页客户端不得导入猫或 demo 模块，检查双色原画、透明留白、不同候选花与节奏、花头/网格贴合、阶段和循环位置/角度连续、240–1920px 范围及静态回退标记。原有 ADR-0006 测试继续保证首页独有挂载。

图集仍是离散姿势，不能表述为真正三维模型或连续骨骼动画。花头定位来自既有原画人工注册。实际动效与生命周期的浏览器验收仍需记录；用户自行打开期间不重开浏览器任务。
