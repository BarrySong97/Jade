# ADR-0008：小猫通过过渡姿势与落地节点切换动作

- 状态：采纳（独立 demo，补充 ADR-0007）
- 日期：2026-09-19

## 背景

用户接受跑跳姿势动画，但指出坐下到奔跑等状态直接切换，没有身体起伏和迈步衔接。仅增加坐起帧仍不能解决飞行中点“休息”瞬间落地、折返直接镜像、重播传送回起点的问题。

## 决定

生成坐站、起跑收步、下蹲恢复和转身四组图集。运行时复用已有坐姿、站姿、跑步接触帧和跳跃姿势作为端点，新帧只填中间段；每图集固定比例，以注册点对齐。

动作序列标出坐稳/站稳的安全节点，新请求排队到下一个节点，连续请求以最后一次为准。腾空必须完成落地恢复，跑段以完整步态周期结束并收步。后续序列继承位置、方向、观察距离和尾巴幅度，不重置画面；尾巴相位独立累计。自动演示回场前缀只执行一次。转身改变朝向后，坐姿与尾巴图层也统一镜像。

仍用原生 Canvas/WebGL，保持独立 demo 和说明性骨架，不新增运行依赖。原始 PNG 和生成提示词留档，不修改或重导出图片。

## 影响与验证

点击动作会有短暂等待，页面显示当前动作与排队请求；拖动进度主动取消请求并暂停。生成帧还可能有细节不一致，不能把时间线连续等同于已完成视觉验收。

[cat-actions.test.mjs](../../scripts/cat-actions.test.mjs) 通过 `pnpm test:meadow` 强制检查安全节点、接续位置/朝向/姿势、飞行不可中断、过渡顺序、起跑收步速度和循环前缀，并解码六张真实图集检查 alpha、间隔、标注及视口边界。浏览器验收仍需实看；延续用户自行打开原 demo 的选择。
