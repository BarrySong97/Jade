# ADR-0011：博客系列使用显式归属与静态归档

- 状态：已采用
- 日期：2026-09-29

## 背景

文章阅读时长旁需要系列入口，打开与首页列表风格一致的系列文章页；首个系列是两篇炒股日记。

## 决策

文章用可选 `series` frontmatter 指定单个系列，标识经 `src/lib/series.ts` 的目录校验，不从标题推断。标识用于 `/series/:series` URL，展示名称可以独立修改。

系列页只为非空系列生成，直接复用首页 `PostArchive` 的按年、新文章优先顺序。组件接受可选文章数组，不传时展示全部文章，空数组不会回退到全站文章。未归属系列的文章不显示入口。

## 影响与验证

增加系列需更新目录并标记文章。首页、系列页共享列表样式；作品和摄影页不受影响。构建检查系列路由，浏览器检查文章到系列再到文章的导航、无系列文章，以及窄屏换行。
