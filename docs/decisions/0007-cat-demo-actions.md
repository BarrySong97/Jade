# ADR-0007：固定视角小猫使用姿势图集与尾巴网格

- 状态：采纳（独立 demo）
- 日期：2026-09-19

## 背景

用户确认照片参考的小猫和手绘三渲二质感，不需要转动视角；要求在原花草 demo 的独立 Canvas 中实际跑跳。坐姿的身体/尾巴分层只适合轻微动作，直接平移或拉伸坐姿不能构成跑步。

## 决定

保留坐姿尾巴网格，跑跳新增透明姿势图集。原生 WebGL 采样当前姿势，纯函数编排状态与地面位移，跳跃用飞行阶段的抛物线控制离地高度。图集统一缩放比例并保存注册点，跑步共用地平线，避免逐帧适应包围盒造成体型变化。

仍在原 `#cat-board`，与花草分开 Canvas、控件、生命周期；只影响 `examples/`，不接入首页、通用布局或作品/摄影页。不增加运行依赖，不引入视频制作框架。

## 影响与验证

可以直观看到四肢收放、蓄力、腾空和落地，并且保留原画笔触。它是关键姿势动画，不是可任意转向的完整骨骼；坐站过渡与生成帧细节仍需视觉迭代。原 PNG 和提示词保留，运行时采样不重写图片。

图集间隔、真实 alpha、动作落点与视口边界纳入 `pnpm test:meadow`。浏览器实际观察仍是视觉验收项；尊重用户自行查看 demo 的选择，不自动重获已交还的浏览器控制权。
