# 0006. 草甸只在首页底部挂载，预览与生产共享二维渲染

- 状态:已采纳
- 日期:2026-09-19

## 背景

用户已在独立花草预览中确认二维透明素材、自然群落排布及微风，并要求直接放到博客首页最底部，明确只放首页。文章与全屏展示页须保持原有边界。

## 决策

BaseLayout 在 Footer 后提供可选 `page-end` 插槽，由首页单独传入 `HomeMeadow`。共享布局和 Footer 不导入草甸。预览和首页复用 `src/lib/meadow-layout.mjs`、`src/components/home/meadow-renderer.js`，继续使用透明位图与二维 WebGL 网格。

## 理由

- 页面显式传入装饰可以保证文章、作品与摄影页不加载草甸；无需在共享布局里判断 URL。
- 同一排布与渲染真源保持设计预览和实际效果一致。固定视角不需要新增三维库。
- Astro 构建期优化 11 张已选 PNG 为最长边 640px 的透明 WebP。静态 SVG 排列同一批位图提供无脚本与 WebGL 失败回退；可见区域附近才创建 WebGL，屏外及后台停止动画。
- 自定义元素负责连接和断开时的资源管理，适配 Astro ClientRouter；减少动态效果时保持静止。

## 后果与强制规则

首页多加载约 650KB 的透明 WebP 与一个小型脚本；静态位图会随 HTML 加载，延后的是解码探测与动画初始化。默认仅微风，大幅弯曲会拉伸画面。静态回退按固定宽度裁切，客户端根据实际宽度排布。

[scripts/meadow.test.mjs](../../scripts/meadow.test.mjs) 已纳入 `pnpm check`：检查草甸只由首页接入、插槽在 Footer 后，并对比共享排布与旧预览计算路径。计数保留原循环的浮点边界，避免改成 `ceil` 后在整倍数宽度出现株数漂移。
