# 0004. 作品集:去掉自动流动瀑布流,改静态两列 + 条目式卡片

- 状态:已采纳
- 日期:2026-07-29

## 背景

`/products` 原本是「左栏简介 + 右侧两列**持续自动流动**的瀑布流」:每列内容复制一份做无缝循环,
奇数列向下、偶数列向上,鼠标移入才「就地冻结 + 可滚动」,还配了一条自定义滚动条。

这套观感是有的,代价也实打实:

- 想看清一张图必须先把鼠标放进去停住流动,**读者不能主动控制**;
- 暂停/恢复要读 `transform` 转 `margin-top` 冻结、再用负 `animation-delay` 续播,一步没对齐就整列跳顶,
  是全站最容易改坏的一段代码(`works.tsx` 里近百行命令式逻辑 + 一堆 ref);
- 作品本身的信息(是什么、什么平台、解决什么)只能塞进图上一个半透明黑徽标里,说不清楚。

用户重新给了参考稿并逐版微调确认:要的是**普通纵向滚动**,重点在单个作品的呈现。

## 决策

作品集改为**静态两列 + 整页纵向滚动**:左栏 sticky 简介不变,右侧两列各自往下堆;
单个作品统一为「线性图标 + 项目名 + 右侧『年份 · 平台』 / 一句说明 / 一张产品图」,
一个项目**只放一张图**。自动流动、hover 冻结、自定义滚动条整套删除。

排版上定一条:**层级靠颜色不靠字号**——整页正文同一号字,说明里 `**重点**` 走墨色、其余灰色
(由 `rich-text.tsx` 渲染)。

## 理由

- 自动流动的全部代码只为它自己服务,删掉后 `works.tsx` 从 161 行的有状态岛变成 ~40 行纯布局,
  showcase.css 也净减(两组循环 keyframes 换成一个载入上浮)。
- 图上叠徽标 vs 图上方一行说明:后者不挡画面、能写完整句子,也让两列在没有图片时依然成立。
- 备选「保留流动但默认暂停」被否:仍要养着那套冻结/续播逻辑,却不再有它换来的观感。
- 分列不用 `i % COLS` 而按图片纵横比贪心装箱:grove 是 9:16 长图,轮转分列会让一列高出一大截。

## 后果

- 好处:交互回到读者手里;首屏不再有持续重绘的动画;作品信息说得清;代码与样式都变薄。
- 代价:两列高度只能**大致**齐,页尾必然留一段空白(masonry 的固有形态,不要用等高硬凑)。
- 附带:左栏大标题取消 → `--serif` 令牌与 Newsreader 字体一并移除(展示页少加载一套字体)。
- 后续别再往回加自动滚动;要加动效先回来改这条 ADR。
