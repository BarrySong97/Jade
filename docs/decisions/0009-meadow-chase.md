# ADR-0009：追蝶使用共享时间线与花头接触点

- 状态：采纳（原花草 demo）
- 日期：2026-09-19

## 背景

用户确定猫半藏在草里，要求先探头观察，待蝴蝶落花后伏低 1–2 秒，再跑起来扑跳，蝴蝶绕开。猫和蝶的两个独立循环无法保证互动时机；仅把蝴蝶放在静态花头坐标上，会在花摇动时悬空。

## 决定

使用原生 WebGL 单画布按后景、猫、前草、蝶绘制；生成伏低/探头、低姿起跑/跑扑和落花/起飞图集，复用既有跑跳与过渡。动物仍由透明原画姿势驱动，不改成三维或完整骨骼系统，不新增依赖。

双方由可采样的共同剧情控制。专注计时在落花完成后开始；逃离时刻由猫进入实际花头接近区求出。花头注册于原图坐标，经过 alpha 裁切、镜像和与植物网格一致的分段风动插值。猫连续移动到另一侧藏身点，再转身伏低，下一轮继承位置和姿势。

舞台只调整自然排布中的两朵花与四株前草，不增加株数。两花、双向、三种时长组成六轮，避免每次完全相同，同时支持确定性暂停/拖动。缩放保持剧情阶段与进度，屏外和后台停表。

## 影响与可执行约束

完整场景先在原 demo 验收；首页目前继续使用已确认草甸。独立动作画板保留。生成 PNG 原样存档并保留提示词；统一比例与注册点只能减少接缝，不能保证跨图集笔触完全一致。

[chase.test.mjs](../../scripts/chase.test.mjs) 已接入 `pnpm test:meadow` / `pnpm check`，带 ADR 编号验证落花后等待、接近后逃离与跑扑顺序，另检查真实花瓣落点、随风贴合、阶段/循环连续、真实轮廓窄屏范围与前草部分遮挡。相位边界采用小容差，防止全局/局部浮点累加让落花后的瞬间仍被判作飞行。

用户自行打开 demo 期间，不另开浏览器任务绕过交还控制；记录程序验证结果与未完成的实屏验收。
